# Test Task Management Service\n\nThis service is responsible for managing the lifecycle of test tasks, including creation, reading, updating, and deletion. It interacts with a PostgreSQL database to persist task definitions.\n\n## Setup Instructions\n\n1.  **Clone the repository:**\n    ```bash\n    git clone https://github.com/p67428378-afk/Test-Task.git\n    cd Test-Task\n    git checkout ISSUE-SCRUM-8\n    ```\n2.  **Create a virtual environment and install dependencies:**\n    ```bash\n    python -m venv venv\n    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`\n    pip install -r requirements.txt\n    ```\n3.  **Database Configuration:**\n    This service requires a PostgreSQL database. Configure your database connection string in an environment variable or a configuration file (e.g., `.env`).\n    Example `.env` content:\n    ```\n    DATABASE_URL="postgresql+psycopg2://user:password@host:port/database_name"\n    ```\n4.  **Run the service:**\n    ```bash\n    uvicorn src.main:app --host 0.0.0.0 --port 8000\n    ```\n\n## Usage\n\nOnce the service is running, you can access the API documentation at `http://localhost:8000/docs` to interact with the endpoints.\n\n## Architecture Notes\n\nThis service is part of a larger microservices architecture for the Test Task System, as described in the High-Level Design (HLD) document. It is designed to be independently deployable and scalable.
